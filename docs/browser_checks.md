# Ручная проверка браузера

В Chrome через локальный Vite проверены начальный экран, подробности R-01, смена демопримера и событие скачивания JSON. Для конфигурации без нарушений показаны пять допустимых соединений. Автоматические тесты импорта вызывают тот же обработчик с объектами File. Системный выбор файлов вручную не проверялся.

Отдельная проверка dist/offline.html подтвердила совпадение встроенного JavaScript с выходом Vite, синтаксическую корректность кода, отсутствие внешних ресурсов script/link и запрет на соединения в CSP. Открытие file:// недоступно в браузерной среде проверки.
