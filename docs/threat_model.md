# Краткая модель угроз

Пользователь выбирает синтетический файл на своём компьютере. Браузер читает только выбранные файлы. Граница доверия проходит между содержимым файла и проверенной моделью. Активы — конфигурация, фиксированная политика и целостность отчёта. Доступная операция пользователя — локальная проверка и сохранение результата. Учётных записей, общей истории и полномочий на промышленном оборудовании у приложения нет.

| Угроза | Мера | Остаточное ограничение |
|---|---|---|
| Чрезмерный объём данных или схема с большим количеством элементов | Размер проверяется перед чтением, ограничения на количество объектов и длину строк — до построения графа | Большие допустимые схемы труднее читать визуально |
| Ошибочная зона, отсутствующее устройство, неверный порт, дубликат ID | Проверка всей конфигурации до замены текущей модели, ошибки на русском | Корректность фактической роли устройства задаёт автор файла |
| Разметка в имени устройства | React выводит данные текстовыми узлами, SVG использует текстовые дочерние элементы. Пользовательские строки не становятся HTML, URL или обработчиками | Безопасность самой среды браузера вне модели |
| Изменение политики через входной файл | Политика поставляется внутри приложения, неизвестные поля отклоняются, исключения привязаны к обоим ID, зонам, типам и сервису | Локальная копия исходного кода доступна владельцу для редактирования |
| Утечка данных или содержимого журнала | Нет внешних API, аналитики, отправки файлов или постоянного хранилища. Журнал содержит технические события и счётчики. Автономный HTML запрещает соединения через CSP | Скачанный отчёт остаётся на диске, доступ к нему контролирует владелец |
| Ложный вывод о доступности PLC | Каждое allow оценивается отдельно, точный конфликт с deny требует проверки, версия политики и область анализа попадают в экспорт | Порядок ACL, NAT, маршрутизация, частичные пересечения, физическая достижимость и подлинность входных данных не проверяются |
| Формула в ячейке экспортированного файла | Экспорт создаёт JSON фиксированной структуры | При дальнейшей конвертации отчёта в таблицу безопасный импорт зависит от выбранного редактора |
